## 已知问题（W3 处理）
- **手机横向溢出**：390px 宽度下表格的最小宽度会把整页撑宽，右侧内容被切掉。修法：给表格加横向滚动容器 + 媒体查询。
- **没有媒体查询**：导航会折行但间距不理想；手机字号偏大。
- **还没有真实图片**：目前全是文字和表格（W3 补截图/照片，并写 alt）。
- **小测验未做**：词汇页现在只有搜索和筛选（W4 加答题小测验）。

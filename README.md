## 功能
- **中英文切换** —— 右上角按钮一键切换；选择记在 localStorage，刷新后保持；也支持 `?lang=en` 直接进英文版（方便分享和测试）
- **词汇表** —— JavaScript 生成表格，**203 个词条**：107 个来自我的课堂笔记、96 个来自 B1 高频词表；搜索 + 按词类/主题双重筛选，支持 `?thema=wetter` 直达
- **笔记页** —— 听写练习 Diktat 7 的原文与订正、词表整理方法
- **联系表单** —— 浏览器原生校验 + 确认信息（本站无后端，页面上已声明）

## 响应式验收（实测数据，不是目测）
用 390px 宽的 iframe 分别加载 5 个页面，读取 `documentElement` 的 `scrollWidth` 与 `clientWidth`：

| 页面 | clientWidth | scrollWidth | 结果 |
| --- | --- | --- | --- |
| index.html | 375 | 375 | ✅ 不溢出 |
| index.html?lang=en | 375 | 375 | ✅ |
| lernen.html | 375 | 375 | ✅ |
| vokabeln.html | 375 | 375 | ✅ |
| kontakt.html | 375 | 375 | ✅ |

做法：所有表格放进 `.table-wrap`（`overflow-x: auto` + `role="region"` + `tabindex="0"`），页面本身永不横向滚动；窄屏媒体查询（≤760px）调字号与间距，宽屏（≥860px）站内导航变两列。

# 德语自习室 Deutsch-Lernzimmer

**线上网址：<https://bazaozhuo.github.io/my-website/>** ✅ 已上线

## 这是什么
Web Development 课程项目。**截止 2026-11-10（周二）**，开发期 4 周。

- 题目：一个**开放的**德语 A2→B1 学习站 —— 词表、知识索引、单词挑战、课堂笔记，谁都能拿去用，觉得缺什么也能补
- 面向读者：中文母语、课业不轻、只有碎片时间的德语学习者
- 技术栈：纯 HTML + CSS + JavaScript（无框架、无后端）
- 部署：GitHub Pages
- 完整计划：`../网页作业-4周冲刺计划.md`

**先说清边界**：本站没有后端。「登录」、学习进度、你投稿的词和建议都只存在**你自己的浏览器**（localStorage），不会上传到任何服务器。所以它是「大家整理好的内容 + 你自己的学习空间」，不是社交网站。

## 功能
- **中英文切换** —— 右上角按钮一键切换；选择记在 localStorage，刷新后保持；也支持 `?lang=en` 直接进英文版。支持两种粒度：`data-i18n`（纯文字）和 `data-i18n-html`（整块带标签的正文，比如知识索引条目里的列表和例句）。共 **258 个 key，0 缺失、0 冗余**
- **词汇表** —— JavaScript 生成表格，**703 个词条**：107 个来自课堂笔记、96 个来自 B1 高频词表、**500 个来自 Netzwerk B1 词汇表（PDF）抽样**；搜索 + 按词类/主题双重筛选，支持 `?thema=wetter` 直达
- **知识索引** —— 20 条静态条目，关键词搜索 + 7 个分类筛选 + 原生 `<details>` 展开；按 `/` 直接跳到搜索框
- **单词挑战** —— 德语→中文 / 中文→德语两种考法；范围（全部 703 / B1 596 / 课本与笔记 107）与题量（10 / 20）可选；答错立刻给正确答案与例句；结束给正确率、本机最高分、错题回顾；键盘 1–4 选择、Enter 下一题
- **首页今日 5 词** —— 随机抽 5 个词做成可翻面卡片，点「学会了」记进度（进度条）
- **投稿与建议** —— 投稿的词会进入本地列表（带「我加的」标签）；建议可一键复制成一段话发给我（因为没后端）
- **图片灯箱** —— 点任意插图放大看，Esc 关闭；`<figure>` + `<figcaption>` + `aspect-ratio` 保证不抖动
- **联系表单** —— 浏览器原生校验 + 确认信息（无后端，页面上已声明）

## 已知取舍（答辩要主动说）
- **知识索引的英文是我自己翻的**：20 条正文（含例句和小标题）都翻了，但德语例句保持原样 —— 那是要学的东西，不翻。
- **"登录"不是真登录**：没有后端，只是在本机记一个昵称。
- **数据换浏览器就没了**：localStorage 的特性，不是 bug。
- **挑战页题库就是词表本身**，没有单独的题库数据。
- **新导入的 500 个词没有例句**（`ex` 为空，表格里显示「—」）：PDF 只有德英对照，逐条配 500 句不现实；以后要补随时加。
- **这 500 个词的词性是按英文释义推断的**（`to …` → 动词、`…ly` → 形容词、有冠词 → 名词），个别可能不准。

## 浅色 / 深色

- 导航右上角太阳/月亮按钮切换，选择存在浏览器里，下次打开还是那个颜色
- 首次访问跟随系统设置（`prefers-color-scheme`）
- 颜色全部走 CSS 变量：`:root` 是浅色，文件末尾 `html[data-theme="dark"]` 覆盖一组值，组件规则不用改
- 页面 `<head>` 里有 6 行内联脚本先定主题再渲染，避免深色用户看到一瞬间白闪

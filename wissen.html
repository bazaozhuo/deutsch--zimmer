语法 过去时 Perfekt / Präteritum日常口语用 Perfekt，书面叙事用 Präteritum

现在完成时 Perfekt 是口语主力：Ich habe gestern einen Film gesehen.

书面叙事（新闻、故事）用过去时 Präteritum：Ich sah gestern einen Film.

haben / sein 的过去时要会说：ich war、ich hatte。

语法 虚拟式 Konjunktiv II表达假设和礼貌请求

假设：Wenn ich Zeit hätte, würde ich mehr lesen.

礼貌请求：Könnten Sie das wiederholen?

常用三件套：hätte / wäre / würde。

Das ist der Kurs, den ich besuche.

关系代词跟着它在从句里的格变：den（阳性第四格）。变位动词在从句末尾。

语法 被动语态 Passivwerden + 过去分词，科技文章里到处是

Die Hausaufgabe wird morgen korrigiert.（作业明天被批改）

结构：werden 变位 + 过去分词放句末；带情态动词变成 muss … korrigiert werden。

语法 从句连词 weil / obwohl / dass / wenn连词后面动词到句末

Ich lerne Deutsch, weil ich in Deutschland studieren will.

这类从属连词一出现，变位动词就被踢到句末（will 在最后）。

语法 可分动词前缀跑到句末，A2 最常错

Ich fange um acht an.（anfangen 分开）

带 an- / auf- / ein- / mit- / zu- 的动词，主句里前缀搬到句末；带情态动词或进从句时又不分：Ich will um acht anfangen.

语法 介词搭配动词 + 固定介词要当成一个整体背

Ich warte auf den Bus.（等公交）

Ich interessiere mich für Musik.（对音乐感兴趣）

介词后面跟第几格是固定的，光背动词没用，要连介词和格一起背。

听力 精听四步：一段胜过十段A2 卡在听不清词与词的分界，靠精听解决
  1. 第一遍：只听，抓大意，不暂停
  2. 第二遍：逐句暂停，写下听到的（写不全也要写）
  3. 对照原文，标出听错的词（通常是弱读小词：ich / auch / nicht / schon）
  4. 最后跟读三遍，模仿语调和停顿
听力 听力材料怎么选课本音频打底，有余力再加慢速新闻

主力：课本配套音频 —— 最贴近考试语速。

补充：德国之声（DW）学习站 的慢速新闻。

只用一个，别同时开五个来源。

写作口语 写作：先套骨架，再换内容B1 写作考的是把话说完整，不是文采
  • 开头感谢：vielen Dank für deine E-Mail / die Einladung!
  • 表达感受：Ich freue mich sehr darüber.
  • 介绍习俗：Bei uns ist … ein wichtiges Familienfest.
  • 礼貌建议：Wir könnten uns in … treffen. / Wie wäre es mit …?
  • 结尾：Viele Grüße / Bis bald!
写作口语 口语：录音复述回听自己的录音，立刻听到以为对了的错误

最笨但最有效的办法：把听过的内容复述一遍并录音，然后回听。

你会立刻听到那些「读的时候以为对了」的错误 —— 尤其是词尾和介词。

材料与安排 材料只用三类课本是主线，辅助材料只解决课本解决不了的问题
  • 课本（主线）：跟着学校德语课的教材和进度走，不另起炉灶
  • 辅助材料：练习册、词典 App（查例句和变位）、课本配套音频
  • 自己造的：错题本、抽认卡、每周写完的作文

原则：不追新 App —— 换材料的时间不如用来多练一遍。

材料与安排 一周 60 分钟怎么排周一到周日各干一件事，照着做就行
  • 周一 词汇：20 个新词，卡在句子里记
  • 周二 听力：精听一段，听 → 写 → 对原文 → 跟读
  • 周三 语法：只攻一个点，做练习册对应题
  • 周四 写作：课本单元主题，写 100 词短文
  • 周五 口语：录音复述周二听的内容
  • 周六 补薄弱环节：哪条线掉队补哪条
  • 周日 整理错题 + 复盘，定下周攻哪个语法点
